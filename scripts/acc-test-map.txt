# Which acceptance tests a pull request runs, by changed file.
#
# Each line: <path glob> <selection>. The first matching line wins; globs are
# bash patterns, matched against repo-relative paths. Selections:
#
#   ALL         run the whole acceptance suite
#   NONE        no acceptance test (docs, release tooling, ...)
#   MIGRATION   only the jdamata migration job
#   <regex>     Go test names, '|'-separated prefixes (go test -run '^(...)')
#
# A changed internal/provider/*_test.go file selects the TestAcc functions it
# defines, unless listed here. A file that matches no line selects ALL, so an
# unlisted new source file is safe by default. Pushes to main, the release
# pull request and the weekly schedule always run everything, so a mapping
# that misses a test only delays the failure, it does not hide it.
#
# TestSelectionMap (internal/provider/acc_map_test.go) checks that every name
# here is a prefix of a real acceptance test, so renames do not go unnoticed.
